File QR

Upload a file, save it to Google Drive, and get a QR code that links to it.

What it is

File QR is a small personal tool run by its owner for their own use. It is not a public service: uploading is protected by a password, and there are no user accounts.

How it works

  1. The owner chooses a file in the File QR web page.
  2. The File QR server saves the file to a folder that the app created in the owner's own Google Drive.
  3. The file is shared as "anyone with the link can view", and the page shows a QR code for that link.

Google Drive access

File QR asks for the drive.file permission only. That lets it see and manage only the files and folder it creates itself. It cannot see, read, or change any other file in your Google Drive.
