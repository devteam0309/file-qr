Privacy Policy

File QR · Last updated October 8, 2026

Who runs File QR

File QR is a personal tool operated by its owner for their own use. It uploads files to the owner's Google Drive and shows a QR code linking to each file. It has no user accounts and no public sign-up.

What Google data File QR accesses

File QR asks for one Google permission: https://www.googleapis.com/auth/drive.file. With it, the app can only create, view, and manage the files and the folder that it created itself. It cannot see, read, change, or delete any other file in the Google Drive account.

Specifically, File QR:

  • creates one folder in the owner's Google Drive to hold uploads;
  • uploads files that the owner chooses into that folder;
  • sets each uploaded file to "anyone with the link can view" so the QR code works;
  • deletes an uploaded file only if sharing it fails, so nothing is left behind half-finished.

How data is used and stored

  • Uploaded files are held in a temporary folder on the File QR server only while they are being sent to Google Drive, and are deleted right after.
  • File QR has no database. It does not keep copies of files, file lists, or usage history.
  • The Google access credential (a refresh token) is stored only in the server's private configuration file and is used only to make the Drive requests described above.
  • A login cookie is used to remember that the owner entered the password. It expires after 12 hours and contains no personal information.
  • File QR does not use analytics, advertising, or tracking of any kind.

Sharing

File QR does not sell, rent, or transfer Google user data to anyone, and does not use it for advertising or to train AI models. The only sharing is the "anyone with the link" setting on each uploaded file, which is the purpose of the app: anyone who has the link or scans the QR code can view that file.

Google API Services User Data Policy

File QR's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

  • Remove File QR's access to your Google account at any time at myaccount.google.com/permissions.
  • Uploaded files live in your Google Drive. Delete them (or the File QR folder) in Google Drive at any time, or change their sharing to stop public access.

Changes
